HtmlTools

A curated collection of single-file web utilities. Each tool is a standalone .html file with embedded CSS and JavaScript—no build step required, ready to host anywhere.

What This Is

This site hosts a browsable catalog of lightweight web apps designed for simplicity and portability. Each tool is self-contained, easy to understand, and trivial to remix or deploy.

  • Stable URLs via GitHub Pages for reliable access
  • Copy/paste friendly code with minimal dependencies
  • No compilation, bundling, or complex setup

Available Tools

  • SVG Arc Generator
    Generate SVG arc paths and curved text with visual controls and real-time preview.
  • SVG Transformer
    Upload or paste SVG, then pan, rotate, scale, and download the transformed result.
