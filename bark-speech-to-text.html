How this works

Bark 3.0 is a 0.6B-parameter English speech model (a fine-tune of NVIDIA Parakeet TDT). It transcribes whole utterances rather than streaming word by word, so "live" mode re-transcribes the sentence you are currently speaking about once a second and shows it in grey, then locks it in when you pause.

The ONNX weights come from ai-ecoverse/Underdog-Bark-3.0-ONNX (CC-BY-4.0, original model by Conway Research) and run on onnxruntime-web's WebAssembly backend inside a Web Worker. Mel features and the TDT decoding loop are plain JavaScript in this file.

Speed depends on your CPU. WebAssembly threads need cross-origin isolation, which most static hosts do not send, so this page may run single-threaded.
