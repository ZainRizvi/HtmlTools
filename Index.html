Hampton-s

A home for small, static-hostable HTML tools — usually a single .html file with inline CSS + JavaScript.

Purpose

This site is meant to be a browsable collection of tiny web apps that are easy to understand, easy to remix, and easy to host (no build step required).

  • Each tool should have a stable URL (via GitHub Pages).
  • Tools should stay copy/paste friendly and keep dependencies light.
